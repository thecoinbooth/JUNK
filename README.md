# JUNK website draft

A responsive, original one-page website inspired by the energy and section flow of the supplied reference site, using the uploaded JUNK artwork.

## Preview
Open `index.html` in a browser. For the most reliable local preview, run a simple local server from this folder:

```bash
python -m http.server 8080
```

Then visit `http://localhost:8080`.

## Replace before publishing

1. `PASTE_YOUR_TOKEN_CONTRACT_ADDRESS_HERE` in `index.html`.
2. The placeholder `#` links for X, Telegram and Discord.
3. Tokenomics, roadmap and buying instructions with verified project information.
4. The demo wallet button with a real, audited integration if needed.
5. The disclaimer and legal text with project-specific wording.

## Files

- `index.html` — page content and structure
- `styles.css` — layout, responsive styles and animations
- `script.js` — menu, reveal animations, modal, lightbox and copy button
- `assets/` — optimized WebP artwork
